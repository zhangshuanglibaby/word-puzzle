# Frontend Checklist

Use this checklist before finishing.

## Visual

- Is there a single clear aesthetic direction?
- Does the typography feel chosen rather than defaulted?
- Are spacing, border radii, and shadows internally consistent?
- Does the most memorable visual idea actually read on first glance?

## Interaction

- Are hover, focus, and loading states visible?
- Does the page still feel coherent on narrow screens?
- Is motion helping rather than distracting?

## Code

- Are colors and spacing centralized where practical?
- Did you avoid unnecessary wrappers and duplicated styles?
- Does the implementation match the existing stack and conventions?

## Final pass

- Remove filler copy if it weakens the design.
- Remove decorative clutter that does not support the concept.
- Favor one bold move over five medium ones.
