# Visual Directions

Use this file when you want a sharper concept before coding.

## Minimal / Quiet

- Large fields of breathing room
- Very few surface treatments
- Strong type hierarchy
- One restrained accent color
- Calm motion, often opacity or translate only

## Organic / Natural

- Soft gradients, mist, paper, water, stone, leaf, sky
- Irregular curves or ink-like silhouettes
- Gentle green, grey-blue, warm light peach, off-white
- Decorative elements should feel atmospheric, not busy

## Editorial / Poster-Like

- Type as a visual object, not just content
- Dramatic scale contrast
- Unbalanced composition that still feels precise
- Large margins and a few strong anchors

## Geometric / Gallery

- Crisp lines, framing systems, deliberate grids
- Strong silhouette shapes
- Quiet neutrals plus one bright accent
- Motion can feel architectural or mechanical

## Futuristic / Neon

- High contrast background
- Glows, grid structures, signal lines
- Tight, precise spacing
- Use sparingly unless the brief asks for spectacle

## Choosing

Pick one of these and commit. Mixing all of them usually produces generic work.
